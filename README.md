
# Projeto: Contagem de Letras em Python

## Objetivo
Este projeto tem como objetivo desenvolver dois programas em Python capazes de contar a frequência de cada letra em um texto digitado pelo usuário.

## Soluções desenvolvidas

### 1. Utilizando FOR
O primeiro programa utiliza a estrutura de repetição for para percorrer o texto e contar quantas vezes cada letra aparece.

Arquivo: modulo_for/contar_letras_for.py

### 2. Utilizando WHILE
O segundo programa utiliza a estrutura de repetição while para percorrer o texto e realizar a contagem das letras.

Arquivo: modulo_while/contar_letras_while.py

## Tecnologias utilizadas
- Python
- Git
- GitHub

## Conclusão
A atividade permitiu praticar funções, variáveis e estruturas de repetição, além de aprender a organizar e compartilhar códigos utilizando o GitHub.
